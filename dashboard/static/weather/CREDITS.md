# Weather photographs

Real photographs selected from Wikimedia Commons to illustrate CSV conditions.
These are representative weather scenes, not photographs of the selected state or date.
The Light rain asset is Wikimedia's official 960px thumbnail; other files are original photographs.
The card crops their display using CSS `object-fit: cover`.

Copies are also kept in the project's `uploads` folder as `weather-partly-cloudy.jpg`,
`weather-showers.jpg`, `weather-light-rain.jpg`, and `weather-sunny-and-hot.jpg`.
