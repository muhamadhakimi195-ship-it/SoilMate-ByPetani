How to read these charts
  • The rain gap compares observed rain with the usual daily rain supplied in the file. The summary above it always describes the last 14 days.
  • Air bars above zero exceed the supplied dry-air line. Below zero means below that line, rather than zero dryness.
  • Soil percentile compares wetness with past conditions. It is not a percentage of water in the soil. The 20/40 reference lines come from the soil file.
  • ESI is shown exactly as supplied. This file contains values above the 0–1 range described by the ECOSTRESS guide, and some reported statuses disagree with the proposed 0.7/0.4 cutoffs. Those cutoffs are not used here until the ESI scale is confirmed.
